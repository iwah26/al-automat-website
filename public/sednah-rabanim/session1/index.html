31 / 48 מה זה API

אוטומציה — חיבור בין מערכות, בלי בן אדם באמצע

אוטומציה

אוטומציה = לגרום לשתי מערכות (או יותר) לדבר ולפעול אחת בשביל השנייה, בלי שאתה צריך להעביר מידע ידנית ביניהן. ה-API הוא השפה המשותפת שמאפשרת את זה.

דוגמה — הבית

כמו להגיע לבית עם קוד כניסה: אתה לא צריך שבעל הבית יפתח לך את הדלת בעצמו — אתה מקליד את הקוד הנכון (הטוקן) בדלת (ה-API), הדלת בודקת שהקוד תקין, ופותחת לך בדיוק את מה שמותר לך להיכנס אליו.

34 / 48 באיזו דלת נכנסים

API, MCP ו-CLI — שלוש דרכים לדבר עם הבית

API

חוקי הבית עצמו — מה מותר לבקש ואיך. לא כלי שמפעילים ישירות, אלא השפה הרשמית של הבית.

MCP

פקיד קבלה שעומד בפתח כל הזמן ומתרגם כל בקשה הלוך-ושוב. נוח — אבל תופס מקום (וטוקנים) גם כשלא צריך אותו.

CLI

כפתור שכבר מחווט מראש לדבר עם הבית. קלוד לוחץ עליו רק כשצריך — בלי מתורגמן שיושב שם קבוע.

"MCP = פקיד קבלה בשכר קבוע. CLI = כפתור בכיס, שמשתמשים בו רק לפי הצורך."
