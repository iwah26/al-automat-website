## חלק ג' — מילון מושגים: API, טוקנים ואבטחה

_עודכן ואושר סופית (12.7.26) — 12 סליידים + דיוידר פתיחה = 13._

1. **דיוידר "ג' — מילון מושגים"**
2. **CLAUDE.md וסוגי הקבצים** — CLAUDE.md (זיכרון קבוע), BRAIN.md (תזכורת), זיכרון (Memory), קבצי עיצוב/תוכן — "כל 'מוח' הוא בעצם קובץ טקסט רגיל"
3. **מה זה API** — אוטומציה = חיבור בין מערכות בלי בן אדם באמצע, + דוגמת הבית עם קוד כניסה
4. **מה זה טוקן API** — עם דוגמת קוד לא-אמיתית (בקשה לשירות מזג אוויר בדוי, `Authorization: Bearer sk-demo-...`)
5. קובץ `.env` — איפה יושבים כל הטוקנים, למה לא נוגעים בו. **כולל:** איך רואים קבצים מוסתרים ב-Mac (`Cmd+Shift+.`) וב-Windows (View → Show → Hidden items)
6. **API מול MCP מול CLI — משל הבית:** API = חוקי הבית עצמו. MCP = פקיד קבלה שעומד בפתח כל הזמן (תופס מקום גם כשלא צריך). CLI = כפתור מחווט מראש, בלי מתורגמן קבוע
7. כל מערכת בענן היא בית (משל הבית ל-API, מלא — GET/POST/DELETE)
8. **Backend** — דף נפרד: "החלק שאף אחד לא רואה"
9. **Frontend** — דף נפרד: "החלק שכולם רואים"
10. **Database** — דף נפרד: "המקום הכי רגיש במערכת"
11. הכלים מאחורי הגב — GitHub / Vercel / Supabase, מהמקלדת לאינטרנט
12. **Skill מול Agent** (ברמת מילון מושגים) — פעולה חוזרת מול מומחה עם שיקול דעת
13. Git workflow — commit/push, מה עולה ל-GitHub ומה לא

**הוסר:** Authentication vs Authorization — יצחק קבע שזה מיותר ולא קשור להקשר הזה.
