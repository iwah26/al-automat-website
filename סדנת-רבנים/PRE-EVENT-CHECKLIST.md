# מה צריך להכין לפני הסדנה
_טופס לשליחה למשתתפים_

---

שלום כבוד הרב,

ברוך הבא לסדנת **"קלוד קוד לרבנים"**.
כדי שנוכל להתחיל לבנות ביחד מהרגע הראשון — יש כמה דברים קטנים להכין מראש.

---

## ✅ רשימת הכנה — עשה לפני המפגש הראשון

### 1. מחשב
- מחשב נייד / נייח עם Windows או Mac
- חיבור אינטרנט יציב
- מסך שניתן לשתף בזום

### 2. התקנות

**א. Node.js**
- כנס לאתר: https://nodejs.org
- הורד את הגרסה "LTS" (הכפתור הירוק הגדול)
- התקן — לחץ "Next" עד הסוף

**ב. Claude Code**
- אחרי שהתקנת Node.js, פתח Terminal (Mac) או Command Prompt (Windows)
- הדבק את השורה הזו ולחץ Enter:
```
npm install -g @anthropic-ai/claude-code
```

### 3. חשבונות שצריך לפתוח — חינם

פתח חשבון בכל אחד מהאתרים האלו לפני הסדנה:

**א. Anthropic — API Key**
- כנס לאתר: https://console.anthropic.com
- צור חשבון
- לחץ על "API Keys" → "Create Key"
- **שמור את המפתח במקום בטוח** — הוא מופיע פעם אחת בלבד

**ב. GitHub — גיבוי הקוד**
- כנס לאתר: https://github.com
- צור חשבון חינמי

**ג. Vercel — פרסום לאינטרנט**
- כנס לאתר: https://vercel.com
- צור חשבון — כנס עם חשבון GitHub שפתחת

**ד. Supabase — בסיס הנתונים**
- כנס לאתר: https://supabase.com
- צור חשבון חינמי
- צור פרויקט חדש — שמור את ה-API Key שמופיע

⚠️ **חשוב:** שמור את כל ה-API Keys במקום אחד (NotePad / Apple Notes). תצטרך אותם בסדנה.

### 4. סקר קצר — ענה לפני המפגש

**א. רמת המחשב שלך:**
- [ ] משתמש בסיסי — אימייל, וורד, מצגות
- [ ] בינוני — יודע להתקין תוכנות, להסתדר לבד
- [ ] מתקדם — יש לי ניסיון עם קוד / אוטומציות

**ב. מה אתה רוצה לבנות בסדנה:**
- [ ] מערכת לניהול הקהילה (מעקב חברים, ימי הולדת, יארצייט)
- [ ] עוזר AI לעבודה היומיומית (תשובות לשאלות, ניסוח מכתבים)
- [ ] יומן אישי חכם

**ג. כמה זמן בשבוע תוכל להשקיע במוצר אחרי הסדנה?**
- [ ] עד שעה
- [ ] 2-3 שעות
- [ ] יותר
