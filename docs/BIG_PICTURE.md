# BIG_PICTURE

## Project Goal
Build a beautiful, high-converting Hebrew business website for "על אוטומט" — a boutique agency that builds smart business processes: automations, bots, CRM systems, AI-integrated workflows, and Claude Code solutions.

The site must also include a CV/Portfolio section focused on the owner's lecture and teaching experience in these fields.

## Target Audience
Israeli businesses and professionals looking to automate and modernize their operations.

## Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Language:** Hebrew (RTL)
- **Deploy:** Vercel

## Pages / Sections
- Hero — bold tagline, CTA
- Services — automations, bots, CRM, AI processes, Claude Code
- About — who is behind "על אוטומט"
- CV / Lectures — professional background, lectures, courses taught
- Testimonials (optional)
- Contact — form or WhatsApp CTA

## Key Constraints
- Full RTL (Hebrew)
- Mobile-first
- Fast load (static generation where possible)
- No CMS needed — content is hardcoded for now
